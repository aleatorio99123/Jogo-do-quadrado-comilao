# Jogo-do-quadrado-comilao
Esse jogo usa **Pygame** na sua interface (ou GUI) e **JSON** para salvar o progresso num arquivo.
## Como jogar:
1. Como o GitHub não deixou eu colocar a pasta, tem um **EXE** nos lançamentos do repositório (mas caso venha com a pasta **ZIP**, extraia ela e continue seguindo os passos)
2. Abra o **EXE** (tem um ícone de moeda estilo super mario)
3. Jogue o jogo (setas para andar)
## notas:
1. O jogo salva sua posição e seus pontos num arquivo **JSON**, o nome é save_joguinho.json
2. Depois de ler, pode apagar esse **README** (ou leiame) sem medo, ele é só um texto de explicação e não um arquivo essencial do jogo
3. Eu não sou profissional em programação então o jogo pode estar ruim

**Aproveite!**
